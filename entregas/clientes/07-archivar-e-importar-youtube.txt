Clientes · Archivar, restaurar e importar

DESCRIPCIÓN
============================================================
Cómo se archiva y se restaura un cliente sin perder su historial, y cómo se cargan muchos clientes de una vez, incluidas varias sucursales de un mismo RNC.

⏱️ CAPÍTULOS
00:00  Archivar y restaurar
00:59  Importar clientes
02:05  El resultado

📋 EN ESTE VIDEO APRENDERÁS
• Archivar un cliente y por qué no borra su historial
• Restaurar un cliente archivado
• Descargar la plantilla y cargar varios clientes con un archivo
• Cargar sucursales de un mismo RNC con el código de cuenta

⚠️ ERRORES COMUNES
• Creer que archivar borra las facturas o la deuda
• Subir un archivo con la razón social distinta para el mismo RNC
• Olvidar el código de cuenta en las sucursales

TRANSCRIPCIÓN
============================================================
Cuando un cliente ya no se usa, no se borra: se archiva. Estamos en Clientes. Recojo el menú. Busco la Ferretería. La lista se filtra mientras escribo. En su fila pulso Archivar, el último icono. El sistema pide confirmar y aclara que el cliente dejará de aparecer en el listado, pero que sus facturas y movimientos se conservan. Confirmo con Sí, Archivar. El sistema avisa que el cliente fue archivado, y pulso Entendido. Ahora el cliente ya no está en la lista. Pulso Ver archivados, y ahí aparece. Para recuperarlo pulso Restaurar. Confirmo, y el cliente vuelve a la lista de clientes activos. El sistema lo confirma, y pulso Entendido otra vez. Archivar tampoco cancela lo que el cliente deba: la deuda sigue en su cuenta.
Para cargar muchos clientes de una vez se usa Importar o Exportar. Abro el diálogo. Tiene tres partes. Primero, descargar la plantilla, en Excel o en CSV, con las columnas, un ejemplo y las instrucciones. Segundo, exportar lo que ya existe, útil para hacer cambios en bloque y volver a subir el mismo archivo. Y tercero, importar el archivo. Cada fila se empareja por documento: si el RNC o la cédula ya existe, se actualiza, y si no, se crea. Si alguna fila tiene errores, no se registra nada: se rechaza el archivo completo. Voy a subir un archivo con dos sucursales de una panadería: el mismo RNC, con códigos de cuenta distintos, PAN guion uno y PAN guion dos, y la misma razón social. Subo el archivo. El sistema lo procesa en cuatro etapas: subir el archivo, validar cada fila, registrar los clientes y finalizar con el resultado. Esto tarda unos segundos.
Terminó la importación. El sistema informa cuántos clientes creó, cuántos actualizó y si hubo errores. Cierro el diálogo y busco el RNC de la panadería. La lista se actualiza sola mientras escribo. Aparecen las dos sucursales de la panadería: cada una con su código de cuenta, PAN guion uno y PAN guion dos, y la misma razón social. Si un RNC ya tiene varias cuentas y el archivo no trae el código de cuenta, el sistema no adivina cuál actualizar: rechaza el archivo y pide el código.
